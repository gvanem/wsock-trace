= loc_set_log_fn(3)

== Name

loc_set_log_fn - Sets the log callback function

== Synopsis
----
#include <libloc/libloc.h>

void loc_set_log_fn(struct loc_ctx* ctx,
	void (*log_fn)(struct loc_ctx* ctx, int priority,
	const char* file, int line, const char* fn, const char* format,
	va_list args));
----

== Description

This function is deprecated and has no effect.

Use link:loc_set_log_callback[3] to send log messages to the calling
application's logging system instead.
